# UNDOC 📋

**UNDOC** is an Android app that helps you track the expiry dates of your important documents — 
vehicle certificates, ID cards, insurance, passports, and more — so you never miss a renewal.

## Features

- **Live Countdown** — Real-time days, hours, minutes, and seconds until expiry
- **Validity Progress Bar** — Visual indicator of how much validity remains, color-coded by urgency
- **Document Categories** — Vehicle, Identity, Insurance, Medical, Travel, Education, Property
- **Image Attachment** — Attach a photo of each document from your gallery or camera
- **Status Badges** — Instantly see if a document is Valid, Expiring Soon, Critical, or Expired
- **Detail View** — Tap any card to see full document info and attached image
- **Persistent Storage** — All data saved locally on your device
- **Clean Light UI** — Minimal, distraction-free interface

## Installation

Download the latest APK from the [Releases](../../releases) page and install it on your Android device.

> Make sure to allow installation from unknown sources in your device settings.

## Requirements

- Android 7.0 (API 24) or higher

## Built With

- Java
- Android Material Components
- SharedPreferences for local storage
- FileProvider for camera integration
